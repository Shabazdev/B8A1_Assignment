# B8A1 — Problem Solving with TypeScript & OOP

This repository contains the B8A1 assignment files.

## Files

- `solutions.ts` — solutions for all eight TypeScript programming problems.
- `type-vs-interface.md` — blog post comparing type aliases and interfaces.
- `type-narrowing.md` — blog post explaining type narrowing with practical examples.

## Blog posts

1. [Type Aliases vs Interfaces](./type-vs-interface.md)
2. [Type Narrowing in TypeScript](./type-narrowing.md)

## Run

Install TypeScript in your project if it is not already installed:

```bash
npm install --save-dev typescript
```

Compile the solution file:

```bash
npx tsc solutions.ts --target ES2020 --strict
```

The assignment asks for a single `solutions.ts` file for all coding answers. The blog posts are kept in separate Markdown files as required.
